# CMU Academic Calendar 2026/27: Appendices Package

This package contains the three calendar appendices in Markdown together with structured reference data.

## Included appendices

1. Manitoba Grade 12 Academic Course List
2. Province-Specific Admission Requirements
3. High School Course Requirements for Admission to Specific Degrees or Majors

## Structured data

- **193** Manitoba Grade 12 course records
- **9** provincial or territorial admission-requirement records
- **16** Appendix C table-row records across **1** source tables

## Important validation note

All files are marked `official_transcription` and `validation_status: pending`. Appendix C contains complex tabular relationships, so the Markdown and ordered cell records should be checked against the PDF or DOCX before being used for definitive prerequisite decisions. Structured values are intended to improve retrieval, not replace the governing calendar.
